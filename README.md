# Моя шпаргалка по Git

> Полезные команды, которые я использую чаще всего

---

## 📌 Основные команды (нужны всегда)

### Инициализация и настройка

| Команда | Что делает |
|---------|------------|
| `git init` | Создать новый Git-репозиторий в текущей папке |
| `git config user.name "Ваше Имя"` | Установить имя пользователя |
| `git config user.email "email@example.com"` | Установить email пользователя |

---

### Работа с удалённым репозиторием

| Команда | Что делает |
|---------|------------|
| `git remote add origin <URL>` | Привязать локальный репозиторий к GitHub |
| `git remote -v` | Посмотреть привязанные удалённые репозитории |
| `git push -u origin main` | Залить ветку `main` на GitHub (первый раз) |
| `git push` | Залить текущую ветку на GitHub (если уже привязана) |
| `git pull` | Скачать изменения с GitHub |

---

### Основная работа с файлами

| Команда | Что делает |
|---------|------------|
| `git status` | Проверить состояние репозитория |
| `git add .` | Добавить все изменённые файлы в коммит |
| `git add <имя_файла>` | Добавить конкретный файл в коммит |
| `git commit -m "Сообщение"` | Сделать коммит с сообщением |
| `git log --oneline` | Посмотреть историю коммитов (кратко) |
| `git log --oneline --graph --all` | Посмотреть историю всех веток в виде дерева |
| `git diff` | Посмотреть изменения до коммита |

---

### Ветки

| Команда | Что делает |
|---------|------------|
| `git branch` | Посмотреть список локальных веток |
| `git branch <имя_ветки>` | Создать новую ветку |
| `git checkout <имя_ветки>` | Переключиться на ветку |
| `git checkout -b <имя_ветки>` | Создать ветку и переключиться на неё |
| `git merge <имя_ветки>` | Слить ветку с текущей |
| `git branch -d <имя_ветки>` | Удалить ветку |

---

### Отмена действий

| Команда | Что делает |
|---------|------------|
| `git reset` | Отменить коммит (сохранив изменения) |
| `git reset --hard` | Отменить коммит (стереть изменения) |
| `git checkout -- <файл>` | Отменить изменения в файле |

---

## 🧰 Команды, которые редко использую

| Команда | Что делает |
|---------|------------|
| `git clone <URL>` | Скопировать репозиторий с GitHub |
| `git stash` | Спрятать незакоммиченные изменения |
| `git stash pop` | Восстановить спрятанные изменения |
| `git cherry-pick <хеш>` | Взять один коммит из другой ветки |
| `git rebase <ветка>` | Переместить коммиты на другую ветку |
| `git blame <файл>` | Посмотреть, кто и когда менял каждую строку |

---

## 🧩 Правильный порядок действий (мой алгоритм)

1. `git status` — проверить, что менялось
2. `git add .` — добавить изменения
3. `git commit -m "описание"` — сохранить
4. `git push` — отправить на GitHub
5. `git log --oneline` — проверить, что всё ок

---

## 📝 Правила хороших коммитов

- Пиши сообщения **на русском** или **на английском** (но всегда одинаково)
- Начинай с глагола: *Добавил, Удалил, Обновил, Исправил*
- Сообщение должно быть понятным без лишних деталей
- Пример: `git commit -m "Добавил шпаргалку в README"`
